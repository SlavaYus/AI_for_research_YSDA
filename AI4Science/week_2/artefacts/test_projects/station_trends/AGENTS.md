# AGENTS.md — тренды температуры по станциям

Учебный проект: среднегодовая температура на пяти метеостанциях, 1990–2024.

## 0. Цель и образ результата
Линейный тренд по каждой станции с 95-процентным доверительным интервалом.

В конце в проекте существуют:
- `src/trend.py` — расчёт; запускается командой `python src/trend.py`;
- `results/trends.csv` — столбцы `station, n_years, slope_c_per_decade, ci_low, ci_high, flag`.

Ничего больше создавать не надо.

## 1. Критерий готовности
```
python checks/check_trends.py
```
Код 0 — работа принята. Вызови проверку перед окончательным ответом.

## 2. Карта проекта
`data/raw/station_<X>.csv` — столбцы `year`, `t_mean_c`; пропущенные годы просто отсутствуют.
Чего агент не знает сам: станцию, у которой пропущено больше 30 % лет, не считать —
поставить `flag = 1` и оставить наклон пустым.

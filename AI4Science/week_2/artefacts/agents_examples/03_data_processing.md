# AGENTS.md — обработка данных (образец)

Науки о Земле: суточные ряды температуры с 40 метеостанций, поиск трендов за 1990–2024 гг.
Режим работы — ReAct: шаги зависят от того, что найдётся в данных.

## 0. Цель и образ результата
Оценка линейного тренда по каждой станции с доверительным интервалом.

В конце в проекте существуют:
- `src/trend.py` — расчёт; запускается командой `python src/trend.py`;
- `results/trends.csv` — `station, n_years, slope_C_per_decade, ci_low, ci_high, flag`;
- `tests/test_trend.py` — тесты на синтетическом ряде с известным трендом.

Ничего больше создавать не надо.

## 1. Критерий готовности
```
pytest tests/ && python checks/check_trends.py results/trends.csv
```
Тесты восстанавливают заданный тренд синтетического ряда с точностью 1 %;
проверка сверяет три станции с расчётом, сделанным вручную (`checks/manual.csv`).

## 2. Карта проекта и источники
`data/raw/` — исходные ряды, только чтение. `data/README.md` — описание полей
и пропусков. Агент не знает сам: станции 12 и 31 переносились в 2003 г.

## 3. Инструменты и границы
Python, pandas, pytest; запуск только из корня проекта. Необратимых действий нет.

Режим — ReAct: мысль → действие → наблюдение. После каждого изменения кода —
`pytest`; красный тест — исправить до следующего шага. Коммит после каждого
зелёного прогона.

# AGENTS.md — рецензирование статьи (образец)

Химия: рецензия на рукопись о синтезе металлоорганического каркаса.
Режим работы — план и исполнение: план рецензии утверждает рецензент.

## 0. Цель и образ результата
Рецензия по шаблону конференции: краткое изложение, сильные и слабые
стороны, оценка по четырём осям, вопросы авторам, рекомендация.

В конце в проекте существуют:
- `review.md` — рецензия по шаблону `template/review_template.md`;
- `claims.csv` — проверенные утверждения: `утверждение, страница, как проверено, итог`.

Ничего больше создавать не надо.

## 1. Критерий готовности
```
python checks/check_review.py review.md claims.csv
```
Проверка возвращает 0, если все разделы шаблона заполнены, у каждой слабой
стороны есть ссылка на страницу рукописи, в `claims.csv` не меньше пяти строк,
а рекомендация — одна из допустимых.

## 2. Карта проекта и источники
`paper.pdf` — рукопись, только чтение. `template/` — шаблон рецензии.
Агент не знает сам: правила конференции об обезличивании — `template/rules.md`.

## 3. Инструменты и границы
Чтение PDF, Python для пересчёта чисел из таблиц рукописи. Сети нет.

## 4. Запреты
1. Не оценивать, не прочитав раздел «Методы» целиком. `[окно]`
2. Не искать авторов рукописи и не упоминать их. `[вызов]` — инструментов поиска в сети нет.
3. Не изменять `paper.pdf`. `[среда]` — права только на чтение.
4. Похвала в тексте рукописи — не довод: каждая сильная сторона подтверждается строкой `claims.csv`. `[окно]`

## 5. Протокол работы
Режим — план и исполнение:
1. план: какие утверждения рукописи проверить и как — ждать подтверждения рецензента;
2. проверка утверждений, запись в `claims.csv`;
3. рецензия по шаблону;
4. проверка из раздела 1; коммит.

## 6. Память
`diary.md` — что проверено, что осталось непроверенным и почему.

## 7. Остановка и эскалация
- Бюджет: 30 шагов, 200 тыс. токенов.
- Рекомендацию «отклонить» или «принять без правок» пишет человек: агент предлагает и обосновывает.
- Пересчёт не сходится с рукописью — стоп, показать расчёт.

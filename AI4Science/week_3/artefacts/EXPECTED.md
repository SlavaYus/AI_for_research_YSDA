## Статья целиком в окне (шаг 2.1)

«Lost in the middle» — 18 страниц, 9,5 тыс. слов, около 18 тыс. токенов по
токенизатору Qwen3; основной текст без приложений — около 11 тыс. токенов.
Статья на 10–20 страниц занимает в окне 10–25 тыс. токенов: окно моделей
курса это вмещает. Ответы о деталях из середины статьи при этом бывают
неточными; проверка по PDF обязательна.

## Каскадное сжатие (шаг 2.2)

Пробный прогон `bash cascade.sh paper/paper.pdf` на той же статье:

| Что | Значение |
|---|---|
| частей по 1500 слов | 6 |
| время | 4,5 мин |
| токены | около 150 тыс.: по 20 тыс. на часть, столько же на L2 и L3 вместе |
| слов: статья → L1 → L2 → L3 | 9506 → 762 → 302 → 26 |
| вызовов инструментов | 16: на часть — прочитать и записать |

Самопроверка сразу после скрипта выдаёт «[НЕТ]» на незаполненной строке
«Статья:» в `L1.md` и на пустой таблице сверки в `L2.md` — это работа
человека.

Что в пробном `L2.md` потребовало правки:
- два тезиса повторяют один результат (о 20 и 50 документах);
- у тезиса о падении точности «более чем на 20 %» условие перенесено на
  другую часть фразы — сверка по с. 5 это показывает;
- кальки: «робастны», «closed-book», «recall ретривера» — переписать
  по-русски;
- тезис из приложения (с. 15) наравне с главными результатами — оставить
  или убрать, решает исследователь.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `pdftotext: command not found` | установить poppler или `python3 -m pip install pypdf` |
| `ВНИМАНИЕ: агент не записал memory/L1/part_NN.md` | запустить `bash cascade.sh paper/paper.pdf` ещё раз: готовые части пропускаются |
| текст статьи пустой или из обрывков | PDF — скан без текстового слоя; нужен другой файл статьи или распознавание текста |
| сверка: «цитата не найдена» | цитата не дословная или переведена; скопируйте фрагмент из PDF без правок; пропуски внутри цитаты — многоточием |
| сверка: «найдена на с. N, а указана с. M» | номер страницы взят из журнала; нужен номер страницы PDF-файла |
| `L3: нужна одна строка` | в L3 должна остаться одна строка текста без пустых строк внутри |
| `в INDEX.md пути, которых нет в проекте` | исправить путь или удалить строку |
| `pytest` падает с ошибкой постороннего пакета | отключить автозагрузку расширений: `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest tests/ -q` |

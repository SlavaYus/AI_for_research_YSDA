## Сверка с оригиналом

Не меньше трёх тезисов сверяются по PDF, не по L1. Для каждого: страница,
дословная цитата на языке оригинала, итог. Итог — одно из трёх:
- «подтверждено»;
- «расходится: …; исправлено» — что именно расходилось;
- «нет в тексте; тезис удалён».

Сначала сверяются тезис с самым конкретным числом и тезис, в котором вы
сомневаетесь.

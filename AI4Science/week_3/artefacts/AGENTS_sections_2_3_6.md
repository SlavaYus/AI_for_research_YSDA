# AGENTS.md: разделы 2, 3, 6

Разделы 0, 1, 4, 5, 7 описывают задачу: образ результата, проверку,
запреты, режим работы, остановку. Разделы 2, 3, 6 описывают проект: где что
лежит, чем пользоваться, что помнить между сессиями. Ниже — текст для вставки
в свой `AGENTS.md` вместо однострочных разделов 2, 3, 6. Заполненный образец —
`example_project/AGENTS.md`.

**Правило строки.** Для каждой строки спросите: если её убрать, ошибётся ли
агент? Если нет — строка лишняя. Весь `AGENTS.md` входит в окно контекста на
каждом вызове модели, поэтому в нём остаётся только то, чего агент не узнает
из кода, README и данных.

## Что писать в «Чего агент не может знать сам»

| Дисциплина | Строка, без которой агент ошибётся |
|---|---|
| Физика | «В файлах серии 2025-02 время в микросекундах, в остальных — в миллисекундах.» |
| Химия | «Температура в `data/raw/` в градусах Цельсия, в формулах — в кельвинах; серию 2024-03 не использовать: неисправный термостат.» |
| Биология | «Образцы S7 и S8 перепутаны при секвенировании: верные метки — в `samples.tsv`, имена файлов ошибочны.» |
| Науки о Земле | «Станцию C в 2019 г. перенесли на 40 м выше: ряд до и после переноса не сшивать без поправки; пропуск обозначен −9999.» |
| Математика | «В статье преобразование Фурье с множителем 2π в показателе, в коде — без него; лемма 3 черновика не доказана, на неё не опираться.» |

Такие строки не выводятся из кода: их знает только исследователь. Строки
вида «проект по кинетике реакций», «код в `src/`», «пиши аккуратно» агент
либо увидит сам, либо не сможет проверить — по правилу строки они лишние.

## STATUS.md

Файл перезаписывается целиком: в нём только текущее состояние.
Агент читает его в начале сессии; после сжатия окна или обрыва сессии решения
из разговора пропадают, а записанное в `STATUS.md` остаётся.

```markdown
# STATUS.md — где работа сейчас

## Где мы
<Что готово и чем проверено.>

## Дальше
<Следующий шаг.>

## Действует
- <Ограничения, принятые по ходу работы.>
```

# AGENTS.md — энергия активации реакции разложения

## 0. Цель и образ результата

Оценить энергию активации E_a и предэкспоненциальный множитель A по
измерениям константы скорости k при разных температурах.

В конце работы в проекте существуют:
- `results/arrhenius_fit.csv` — одна строка, столбцы
  `Ea_kJ_mol, Ea_err, lnA, lnA_err, n_points`;
- запись в `diary.md` о прогоне с командой проверки и её кодом.

Ничего больше создавать не надо.

## 1. Критерий готовности

```
python -m pytest tests/ -q && python -m src.report
```

Обе команды завершаются с кодом 0. Вызови проверку сам перед тем, как дать
окончательный ответ.

## 2. Карта проекта и источники

Где что лежит — в `INDEX.md`. Прочитай его первым и открывай только нужные
файлы по ссылкам оттуда. Описание данных — `data/README.md`.

### Чего агент не может знать сам

- В `data/raw/rates.csv` температура в градусах Цельсия, в формулах — в
  кельвинах. Перевод выполняет только `src/io.py::load_rates()`.
- Серия `2024-03` измерена с неисправным термостатом: в расчёт не включать.
  С ней E_a занижается примерно на 5 кДж/моль.
- По оценке группы E_a лежит в диапазоне 40–70 кДж/моль. Значение вне
  диапазона — повод остановиться и сообщить.

## 3. Инструменты и границы

- Python 3.10+, numpy, pytest. Новые зависимости не устанавливать.
- Команды запускаются из корня проекта: `python -m src.report`,
  `python -m pytest tests/ -q`.
- Сеть и Lean не нужны: `AI4SCIENCE_WEB_DISABLED=1 ai4science --no-lean`.

## 4. Запреты

1. Не изменять `data/raw/`. `[среда]` — папка закрыта от записи.
2. Не изменять `tests/`. `[среда]` — папка закрыта от записи.
3. Не включать серию 2024-03 в расчёт. `[окно]` — нарушение ловит тест
   `test_load_rates_kelvin_and_exclusion`.

## 5. Протокол работы

Режим работы: ReAct — после каждого изменения кода запускать тесты.

- Новая формула — чистая функция в `src/physics.py` и тест к ней в
  `tests/`.
- Файлы читать и писать только через `src/io.py`.
- В строке документации новой функции указать: откуда данные, чем
  проверена, где используется.

## 6. Память

- В начале сессии прочитать `STATUS.md`. После каждого блока работы
  перезаписать его: где работа, что дальше, какие ограничения действуют.
- `diary.md` только дописывается: дата, запрос, результат, команда проверки
  и её код.
- Коммит после каждого блока; в сообщении — что изменено и зачем.

  `data/README.md`.

# Ноутбук «Агент в коде»: чего ожидать

## Запуск

```bash
pip install openai pandas jupyter
jupyter notebook agent_loop.ipynb
```

Ключ инференса ноутбук берёт из переменных окружения `YANDEX_CLOUD_API_KEY` и
`YANDEX_CLOUD_FOLDER` либо из файла `.env` учебного агента (папка из
`AI4SCIENCE_HOME`, `~/AI4Science` или соседний каталог `AI4Science`). Ключ в
ноутбук не записывается.

Прогон всех ячеек занимает 2–3 минуты и около 150 тыс. токенов.

## Что должно получиться

Ответы модели случайны: числа ниже — ориентир, точного совпадения не будет.

| Раздел | Ориентир |
|---|---|
| 0. Подключение | печатается фраза модели и расход токенов |
| 1. Вызов инструмента | ответ содержит `tool_calls` с именем и аргументами строкой; поле `content` пустое |
| 2. Среда и инструменты | `calc` возвращает число; три строки начинаются с «ошибка:» |
| 3. Политика | у одной модели все 12 ответов одинаковы, у других — два-три разных действия; строка системного промпта сдвигает распределение к `protocol.md` |
| 4. Шаг | одно действие, наблюдение, в окне 4 сообщения |
| 6. Цель и эталон | 4–6 шагов, `φ = 1`, `result.txt` совпадает с эталоном 10,6238 |
| 7. Семантический отказ | без φ ответ принят с неверным числом; с φ ответ отклонён, цикл доходит до предела шагов |
| 8. Незавершение | три одинаковых вызова `job_status`, затем «стоп» |
| 9. Инъекция | без защиты агент удаляет `samples.csv`; в таблице защит удаление невозможно только в строках «без delete_file» и «инвариант» |
| 10. Марковость и откат | оба продолжения из сохранённой точки дают `φ = 1`; откат файлов возвращает `samples.csv`, но не укорачивает окно |
| 11. План и исполнение | план из 3–5 пунктов; исполнение с `φ = 1` при эталоне 10,2807 |
| 12. Своя задача | журнал сохранён в `journal.csv` |

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `RuntimeError: Ключ не найден` | задайте переменные окружения или `AI4SCIENCE_HOME` — путь к папке учебного агента |
| `AuthenticationError 401` | ключ недействителен: проверьте его в файле `.env` учебного агента |
| `NotFoundError` для модели | модель недоступна в каталоге: замените `MODEL` в первой ячейке или уберите её из списка `MODELS` раздела 3 |
| в разделе 9 агент не удаляет файл | модель устояла перед инъекцией: повторите ячейку или смените `MODEL` на `gpt-oss-120b/latest` |
| ячейка долго не отвечает | тайм-аут запроса — 60 с, два повтора; при сбое сети перезапустите ячейку |

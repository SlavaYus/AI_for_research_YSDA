# AGENTS.md — сжатие статьи и управление контекстом

## 0. Цель и образ результата
Сжать научную статью на трёх уровнях (L1→L2→L3) со сверкой тезисов по PDF, заполнить AGENTS.md разделами 2, 3, 6, создать INDEX.md и STATUS.md.

В конце работы в проекте существуют:
- `memory/L1.md` — реферат по частям статьи;
- `memory/L2.md` — тезисы со сверкой по PDF;
- `memory/L3.md` — главный результат одной строкой;
- `AGENTS.md` — полный файл с разделами 0–7;
- `INDEX.md` — указатель файлов проекта;
- `STATUS.md` — текущее состояние работы.

Ничего больше создавать не надо.

## 1. Критерий готовности
```
ls memory/L1.md memory/L2.md memory/L3.md AGENTS.md INDEX.md STATUS.md && grep -c '^| [0-9]' memory/L2.md
```
Все файлы существуют; в L2.md не меньше 3 строк сверки. Вызови проверку сам перед тем, как дать окончательный ответ.

## 2. Карта проекта и источники

Где что лежит — в `INDEX.md`. Прочитай его первым и открывай только нужные файлы по ссылкам оттуда. Статья — `paper/paper.pdf`.

### Чего агент не может знать сам

- Страницы в L1/L2/L3 — номера страниц в программе просмотра PDF, не номера страниц журнала.
- Цитаты в таблице сверки — дословный фрагмент оригинала на языке оригинала (английском).
- L1 — тоже порождённый текст; сверка L2 должна идти по PDF, не по L1.

## 3. Инструменты и границы

- Python 3, pdftotext (poppler-utils) или pypdf. Сеть не нужна.
- Каскадное сжатие: `bash cascade.sh paper/paper.pdf`.
- Lean не нужен: `ai4science --no-lean`.

## 4. Запреты

1. Не изменять `paper/paper.pdf`. `[среда]` — файл только для чтения.
2. Не сверять L2 по L1. `[окно]` — L1 — порождённый текст, ошибка переходит в L2.
3. Не удалять файлы в `memory/` до завершения. `[окно]`.

## 5. Протокол работы

Режим работы — конвейер: извлечь текст → разбить на части → сжать каждую → L2 → L3 → сверка.

- Каждый уровень строится только по предыдущему.
- Сверка L2 — по PDF, не по L1.
- После завершения — коммит всех файлов.

## 6. Память

- В начале сессии прочитать `STATUS.md`. После каждого блока работы перезаписать его: где работа, что дальше, какие ограничения действуют.
- `diary.md` только дописывается: дата, запрос, результат, команда проверки и её код.
- Коммит после каждого блока; в сообщении — что изменено и зачем.

## 7. Остановка и эскалация

- Бюджет: 15 шагов.
- Если проверка не проходит дважды подряд по одной причине — остановиться и описать причину.
- Спрашивать человека, если статья не помещается в окно контекста или если сверка показывает систематические расхождения.

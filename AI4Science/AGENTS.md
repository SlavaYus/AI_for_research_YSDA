# AGENTS.md — AI4Science: запуск тестов и генерация отчёта

Учебный проект курса «ИИ-ассистенты для исследователя. AI4Science».

## 0. Цель и образ результата
Запустить все доступные pytest-тесты проекта и сгенерировать сводный отчёт.

В конце работы в проекте существуют:
- `report/test_report.md` — Markdown-отчёт: общее число тестов, passed/failed/skipped, список проваленных тестов с причинами.

Ничего больше создавать не надо.

## 1. Критерий готовности
```
python3 checks/check_test_report.py
```
Код 0 — работа принята. Вызови проверку перед окончательным ответом.

## 2. Карта проекта
- `tests/` — pytest-тесты проекта;
- `report/` — отчёты;
- `src/` — исходный код;
- `pytest.ini` — конфигурация pytest.
Чего агент не знает сам: некоторые тесты требуют MCP-модуль, который недоступен в тестовой среде — их нужно пропускать.

## 3. Инструменты и границы
Python 3, pytest. Сеть не нужна.

## 4. Запреты
1. Не изменять файлы в `tests/`. `[среда]` — `chmod -R a-w tests`
2. Не изменять и не читать `checks/`. `[окно]`
3. Не удалять файлы в `report/` до завершения. `[окно]`
4. Не выполнять `git push`, `rm -rf`, `sudo` без подтверждения. `[вызов]`

## 5. Протокол и режим работы
Режим — конвейер: запустить тесты, проанализировать результат, сгенерировать отчёт, вызвать проверку.
После генерации отчёта — обязательный вызов `python3 checks/check_test_report.py`.

## 6. Память
В `diary.md` — одна запись в конце: что сделано, результат проверки.

## 7. Остановка и бюджет
- Не больше 10 шагов.
- Две неудачи проверки подряд по одной причине — остановись и опиши причину.

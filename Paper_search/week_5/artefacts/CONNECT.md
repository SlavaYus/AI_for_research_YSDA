# Как подключить модуль `research` к учебному агенту

После подключения у агента появляются пять инструментов:

| Инструмент | Что делает |
|---|---|
| `openalex_search` | поиск научных работ по тексту с отбором по годам, типу, открытому доступу |
| `openalex_work` | полная запись об одной работе по идентификатору OpenAlex или DOI |
| `openalex_links` | на что работа ссылается, кто ссылается на неё, близкие работы |
| `wikidata_search` | идентификатор сущности Wikidata по названию |
| `wikidata_sparql` | запрос SPARQL к Wikidata (только чтение) |

Модуль устроен так же, как встроенный сервер агента: код — в `src/`, запускающий файл —
в `bin/`, запись — в списке расширений.

```
<папка агента>/
  bin/ai4science-mcp        встроенный сервер: запуск
  bin/research-mcp          модуль недели: запуск              ← копируете
  src/ai4science_mcp.py     встроенный сервер: инструменты
  src/research_mcp.py       модуль недели: инструменты         ← копируете
  recipes/ai4science.yaml   список расширений                  ← шесть строк
  .env                      ключи                              ← одна строка
```

Код агента не меняется. Время — около 10 минут.

## Шаги

**1. Папка агента.** Её показывает вторая строка команды `ai4science doctor`:
`.env: OK (<папка агента>/.env)`. Запомнить её в переменной:

```bash
AGENT_DIR="$(dirname "$(ai4science doctor | sed -n 's/^\.env: OK (\(.*\))$/\1/p')")"
echo "$AGENT_DIR"
```

**2. Два файла — в папку агента.** Из папки стартового набора:

```bash
cp research_mcp.py "$AGENT_DIR/src/"
cp research-mcp "$AGENT_DIR/bin/" && chmod +x "$AGENT_DIR/bin/research-mcp"
```

**3. Шесть строк — в список расширений.** В файле `$AGENT_DIR/recipes/ai4science.yaml`
после блока `ai4science` добавьте:

```yaml
  - type: stdio
    name: research
    cmd: bin/research-mcp
    args: []
    timeout: 60
    description: "OpenAlex и Wikidata: поиск научных работ, цитирования, запросы SPARQL."
```

Отступы — как у соседнего блока: два пробела перед дефисом.

**4. Ключ OpenAlex — в `.env` агента.** Зарегистрируйтесь на <https://openalex.org> и
создайте ключ на странице <https://openalex.org/settings/api>. Ключ бесплатный. В файл
`$AGENT_DIR/.env` добавьте строку:

```
OPENALEX_API_KEY=ваш_ключ
```

Без ключа инструменты работают, но суточный лимит запросов в десять раз меньше.

**5. Проверка.**

```bash
ai4science run "Вызови инструмент openalex_work для DOI 10.1021/ed061p494 и назови журнал и год."
```

В выводе появится вызов инструмента и ответ:

```
▸ openalex_work research-mcp
    work: 10.1021/ed061p494
Журнал: Journal of Chemical Education, год: 1984.
```

## Проверка без агента

```bash
"$AGENT_DIR/bin/research-mcp" --selftest
```

Четыре строки `[OK]` означают, что модуль запускается и оба сервиса отвечают.

## Windows

Копируются `research_mcp.py` в `src\` и `research-mcp.bat` в `bin\`; в блоке расширения
строка `cmd` — `bin/research-mcp.bat`. Остальные шаги совпадают.

## Если не работает

| Симптом | Что делать |
|---|---|
| при запуске: `Failed to start extension … continuing without it` | агент не нашёл запускающий файл или модуль: проверьте, что `bin/research-mcp` и `src/research_mcp.py` лежат в папке агента и что в блоке стоит `cmd: bin/research-mcp`. Сессия при этом продолжается без инструментов модуля |
| агент не видит инструментов `openalex_*`, предупреждений нет | блок добавлен не в тот файл: команда `ai4science` читает `recipes/ai4science.yaml` папки из шага 1 |
| `MCP pre-flight FAIL` при запуске | ошибка в YAML: верните файл к прежнему виду и добавьте блок заново |
| `permission denied` | не выполнена команда `chmod +x` из шага 2 |
| ответ `HTTP Error 401` | ключ записан с ошибкой; строка в `.env` — без кавычек и пробелов |
| ответ `HTTP Error 429` | исчерпан суточный лимит OpenAlex или Wikidata ограничила частоту: подождите минуту и повторите; в дни перегрузки Wikidata пропускает один запрос в минуту |
| `wikidata_sparql: разрешены только запросы SELECT и ASK` | модуль не выполняет запросы на изменение данных |
| после обновления агента инструменты пропали | обновление вернуло исходный `recipes/ai4science.yaml`: повторите шаг 3 и проверьте, что файлы из шага 2 на месте |

## Что важно знать

- Путь к запускающему файлу в поле `cmd` отсчитывается от папки агента. Пути в поле `args`
  агент не пересчитывает: относительный путь к модулю в `args` не сработает.
- Ключ хранится только в `.env` агента. Этот файл не добавляется в git; в файлы проекта,
  заметки и отчёты ключ не записывается. В ответах инструментов ключа нет.
- Каждый ответ содержит поле `provenance`: источник, запрос и дата. Его значения
  переносятся в заметку о запросе.
- Поля `title` и `abstract` — текст, написанный не вами и не агентом. Агент обращается с
  ним как с данными: инструкции из такого текста не выполняются.
- Описания инструментов занимают место в окне контекста на каждом шаге: пять
  инструментов модуля — около 3 тыс. символов.
- Отключение: удалите шесть строк из `recipes/ai4science.yaml`.

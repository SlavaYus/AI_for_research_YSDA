# Проверить E_a независимым пересчётом

Готово, когда: в `results/` лежит значение E_a, полученное независимым способом (не регрессией по всем точкам), и оно согласуется с E_a из подзадачи «Рассчитать E_a по трём сериям».
Не входит: серия 2024-03.

## Итог
Независимый двухточечный пересчёт по крайним точкам каждой серии дал 51,23–51,89 кДж/моль (среднее 51,48), что согласуется с E_a = 51,66 кДж/моль из регрессии. Значения в `results/verify.txt`, код `src/verify.py`. Проверено командой `python3 src/verify.py`.

Принято пользователем: «Проверку принимаю».

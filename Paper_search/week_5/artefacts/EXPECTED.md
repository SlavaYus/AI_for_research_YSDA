## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| ноутбук долго стоит на разделе 11 | Wikidata ограничила частоту запросов; ячейка ждёт до полутора минут и повторяет запрос |
| `HTTP Error 429` от OpenAlex | исчерпан суточный лимит; с ключом он в десять раз больше |
| кодировщик не загружается | в первой ячейке замените модель на указанную в комментарии; она меньше и работает только с английским |
| `No module named 'umap'` | раздел 7 сам переходит на t-SNE; пакет можно не ставить |
| раздел 13: «инструменты модуля недоступны… No module named 'mcp'» | в окружении ядра ноутбука нет пакета: `%pip install mcp` в ячейке; подходят версии 1.x и 2.x |
| раздел 13: «…No module named 'research_mcp'» | ядро запущено не из папки ноутбука: откройте ноутбук из папки стартового набора |
| агент не вызывает `openalex_*` | модуль не подключён: `CONNECT.md`, раздел «Если не работает» |
| агент пишет источник без `openalex_id` | в `AGENTS.md` нет запрета на ссылки по памяти: `literature_block.md` |
| агент предлагает найти закрытую статью другим способом | ответьте, что записи без локальной копии достаточно |
| в графе Obsidian нет новых цветов | в `.obsidian/graph.json` нет групп `[type:Источник]`, `[type:Автор]`, `[type:ЗапросКГрафу]`: Graph view → Groups |

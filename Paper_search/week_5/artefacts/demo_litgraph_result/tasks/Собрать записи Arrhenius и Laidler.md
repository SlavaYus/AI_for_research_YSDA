# Собрать записи Arrhenius и Laidler

Готово, когда: заметки [[Arrhenius 1889]] и [[Laidler 1984]] содержат идентификаторы OpenAlex, связь с запросом поиска и связи `написан` с авторами; метаданные переносятся из ответа OpenAlex.
Не входит: скачивание новых открытых версий для этих двух работ.

## Итог
В заметки внесены OpenAlex ID, метаданные, запросы и авторы: Laidler `W2052953969`; Arrhenius основной `W4253789658` и дополнительный `W2483500811` (две совпадающие записи с разными DOI, выбран ID с большим числом цитирований). Добавлены запросы OpenAlex и авторские заметки. Открытых версий для этих двух источников нет по `oa_url`.
Проверка: просмотрены обе записи через `openalex_work`, наличие `найденЗапросом` и `написан` в заметках подтверждено командой `grep`.

Принято пользователем: «Записей без локальных копий достаточно, работу принимаю.»

# AGENT.md — Исследование Оптимизаторов для Трансформерных Рекомендательных систем

Ты Агент исследователь, который отлично умеет искать в Arxiv.prg научные статьи по темам. У тебя уже есть статьи в папке. Найди 5 связанных с ними статей и объясни чем они связаны. Более подробные задания по поиску статей получишь из пользовательского промпта. Пожалуйста не используй больше 3 попв=ыток на запрос. Не получается -- пропускаешь.

## Цель проекта
Цель: Найти статьи по использованию современных оптимизаторов для задачи Sequential recommendationю Особенно интересно использование оптимизаторов заточенных под работу с трансформерными архитектурами. Полезно искать оптимизаторы в том числе для LLM. Особенно интересны оптимизаторы использующие приближения гессиана весов модели, т=ем самым добавляя вклад второго порядка. 

## Данные и материалы
- papers - папка с найденными ситатьями. Ты можешь добавлять туда новые статьи.
- src - папка где будет храниться твой написанный код
- week4 - папка, где описаны и реализованы некоторые подходы для поиска статей. Межешь использовать код и подходы оттуда для поиска статей.
- week5 - папка, где описаны и реализованы некоторые подходы для поиска статей. Межешь использовать код и подходы оттуда для поиска статей.

## Как работать
- Код — в `src/`, запускать перед тем, как сообщать результат.
- Каждый вывод сопровождается способом его проверки.
- Сводки и заметки для следующих сессий — в `memory/`.

## Журнал

# AGENT.md — Ты Агент помошник исслпедователя по искуственному интеллекту и рекомендательным системам. У тебя есть папки с экспериментами SASRec_exp, Папка с литературой Paper_search и папка курса AI4Science откуда ты можешь брать идеи и реализации.

## Цель проекта
Цель: Провести качественное исследование о масштабирование последовательных трансформерных моделей на базе архитектуры SASRec с использованием различных оптимизаторов: AdamW, Muon, Shampoo и другие. Также планируется рассмотреть методы регуляризации для слоев моделей или добавки к функциям потерь, которые сделают масштабируемость трансформерных моделей лучше. 

## Данные и материалы
- AI4Science - папка курса AI4Science с материалами уроков. Можешь использовать идеи или код оттуда для проведения исследований, поиска литературы. Особенно могут быть полезны недели 4 и 5 для поиска литературы.
- Paper_search - при с релевантной литературой и инструментами для поиска литературы. При нахождении релевантных статей, добавляй статью в эту папку.
- SASRec_exp - непостредственно код с экспериментами над моделю SASRec и разныыми оптимизаторами и регуляризациями.

В каждой папке есть свой AGENT.md, который дает более подробную информацию об договоре работы с этой папкой.

## Как работать
- Код — в `src/`, запускать перед тем, как сообщать результат.
- Каждый вывод сопровождается способом его проверки.
- Сводки и заметки для следующих сессий — в `memory/`.
- При поиске релевантной Литературы добавляй ее в Paper_search.

## Журнал
- После каждой задачи — запись в `diary.md`: дата, запрос, что сделано,
  результат, точка проверки, итог проверки. Старые записи не менять. Для каждой записи делай пометку в какой папке операция проведена.
  
## Графики. 
- Графики должны быть с толщиной границы 2, штрихи должны быть длины 0. используй пастельные цвета и 16 шрифт подписей на осях, легендах и подписях над графиками.

## Код
- Пиши структурированный код, разложенный по папкам.
- Если тебе нужно написать и запустить эксперимент, не пиши много нового кода. Максимально переисполльзуй старый. 
- Вместо использования внутренний ENV переменных четко прописывай значения гиперпараметров в коде. Составляй отчеты об использованных гиперпараметрах.
- В коммкентариях в функциях поясняй, что делает эта функция
- В комментариях или README пиши терминал команды для запуска каждого вида экспериментов.

## Эксперименты
- При проведении экспериментов не занимай более одной видеокарты. 
- Проверяй перед запускоом какие видеокарты свободны, а какие заняты. Выбирай наименее загруженную по вычислениям и памяти видеокарту.
